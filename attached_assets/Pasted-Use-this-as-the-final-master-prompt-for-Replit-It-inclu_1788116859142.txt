==================================================
1. CURRENT PROBLEMS TO FIX
==================================================
The existing Split feature is visually improving but functionality is still too basic.
Current problems include:
1. Folder totals do not always display or calculate correctly.
2. Shared folder members cannot be properly allocated items/amounts.
3. It is difficult or impossible to decide exactly who owes what.
4. Receipt line items cannot be assigned individually.
5. Manual expenses are not flexible enough.
6. Invited people are not properly integrated into allocations.
7. Folder sharing is too basic.
8. We need native phone sharing like the iPhone Share Sheet.
9. Payment requests are not fully functional.
10. Stripe Connect payment functionality must be implemented correctly.
11. Stripe Checkout / receipt must show what the person is actually paying for.
12. Paid-by and owes-to logic must be separated.
13. Existing Split Folder screens are too static and need to become actionable workspaces.
